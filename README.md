## 🥊 Proyecto destacado

### Gym Management SaaS

Plataforma SaaS orientada a gimnasios y academias de **MMA, Brazilian Jiu-Jitsu, Grappling y Boxeo**.

La aplicación permite gestionar:

- 👥 Socios
- 🥊 Entrenadores
- 📅 Clases
- 🎟️ Reservas
- 💳 Tarifas
- 🔐 Roles y permisos
- 🏢 Diferentes gimnasios

👉 [Ver el proyecto](https://github.com/Sergifbb/gym-management-saas)
